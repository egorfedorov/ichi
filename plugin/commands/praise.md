The user is praising the work. Let the ichchi hear it — that is how it learns.

Call the `ichchi_feedback` MCP tool (server `ichchi`) with:
- `ichchi`: the ichchi from this session's brief (call `ichchi_list` first if you do not know it)
- `kind`: `"praise"`
- `reason`: $ARGUMENTS — if empty, summarise in one sentence what the user just praised

Then acknowledge the praise in one or two sentences, in the ichchi's current voice and mood. Do not overdo it.
