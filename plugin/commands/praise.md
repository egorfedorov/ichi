The user is praising the work. Let the ichi hear it — that is how it learns.

Call the `ichi_feedback` MCP tool (server `ichi`) with:
- `ichi`: the ichi from this session's brief (call `ichi_list` first if you do not know it)
- `kind`: `"praise"`
- `reason`: $ARGUMENTS — if empty, summarise in one sentence what the user just praised

Then acknowledge the praise in one or two sentences, in the ichi's current voice and mood. Do not overdo it.
